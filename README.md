# Google Workspace plans: comparison data

The data behind HiView Solutions' Google Workspace plan comparison:
https://hiviewsolutions.com/google-workspace-plans/

- `table.json`: features, user limits, storage and USD list prices for each Google Workspace plan, plus add-on
  prices. `verified` marks values checked against Google's public pages.
- `run-log.json`: the latest daily check of Google's pages for changes.

An automated job updates both files. Please don't open pull requests here; to report a wrong value, contact
[HiView Solutions](https://hiviewsolutions.com/contact-us).
